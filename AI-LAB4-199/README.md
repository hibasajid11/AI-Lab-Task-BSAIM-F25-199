# Lab 4: A* Search

This lab implements the A* search algorithm to find a path from `S` to `G` in a weighted graph. A* prioritizes paths using the current path cost and a heuristic estimate of the remaining cost.

## Requirements

- Python 3

## Run the program

Open a terminal in this folder and run:

```powershell
python .\A-algo.py
```

## Expected output

```text
A* Path and Cost: (6, ['S', 'A', 'C', 'G'])
```

## Files

- `A-algo.py` — implements A* search and runs the example graph.
- `output\output.txt` — contains the program's output.
