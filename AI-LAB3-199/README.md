# Lab 3: Uniform Cost Search

This lab demonstrates Uniform Cost Search (UCS) on a small weighted graph. The algorithm uses a priority queue to explore paths in order of their cumulative cost and returns the least-cost path to the goal.

## Requirements

- Python 3

## Run the program

Open a terminal in this folder and run:

```powershell
python .\lab3_ucs.py
```

## Expected output

```text
UCS Result: (3, ['A', 'B', 'E', 'G'])
```

## File

- `lab3_ucs.py` — defines the weighted graph, implements UCS, and searches for a path from `A` to `G`.
