# Lab 5: Minimax with Leaf Counter

This lab implements the minimax algorithm for a binary game tree. It evaluates the leaf scores, alternates between maximizing and minimizing levels, and counts the number of leaves evaluated.

## Requirements

- Python 3

## Run the program

Open a terminal in this folder and run:

```powershell
python .\lab5_minimax.py
```

## Expected output

```text
Optimal Value: 5, Leaves Evaluated: 8
```

## Files

- `lab5_minimax.py` — implements minimax and runs the example.
- `output.txt` — contains the program's output.
